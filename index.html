Approval-gated workflow

  1. Preview the proposed product pulse and action.
  2. Request approval for the specific action.
  3. Review the pending action and explicitly approve it.
  4. Execute only after approval: append the report to Google Docs or create an unsent Gmail draft.
Prototype limitation: This page is a presentation demo. It does not run live review analysis or execute Google Docs/Gmail actions. Those actions are implemented separately in the MCP workflow.
